Sincronização

Sincronize seus dados entre celular, tablet e computador usando um repositório privado do GitHub como cofre — grátis, sem servidor próprio.

  1. Crie um repositório privado no GitHub (vazio serve). Ele guardará um único arquivo com seus dados.
  2. Em github.com/settings/tokens, gere um token fine-grained com permissão Contents: Read and write apenas para esse repositório.
  3. Preencha abaixo — e repita este passo nos seus outros dispositivos.

O token fica salvo apenas neste navegador. Com ele, o app só consegue ler e gravar o arquivo de dados nesse único repositório — nada mais.
